# Farmacia La Venadita — Sitio web informativo

[![CC BY-NC 4.0](https://licensebuttons.net/l/by-nc/4.0/88x31.png)](https://creativecommons.org/licenses/by-nc/4.0/)

Sitio web informativo para **Farmacia La Venadita**, una farmacia veterinaria real ubicada en Fresnillo, Zacatecas, especializada en animales de granja.

🔗 **Sitio en vivo:** https://veterinaria-la-venadita.site.je/?i=1

> ⚠️ **Proyecto en construcción.** Este README documenta el proceso de desarrollo y se irá actualizando conforme avance el sitio.

---

## 📋 Sobre el negocio

Farmacia La Venadita ofrece:

- Venta de medicamentos y utensilios para uso veterinario.
- Atención directa y personal por el veterinario **M.V.Z. Jorge Luis Solís Recéndez**.
- Los mejores precios del mercado.
- Surtido amplio para manejo, medicina preventiva y curativa de la mayoría de las especies.
- Cotización y obtención de la mayoría de medicamentos del mercado, incluso si no se encuentran en el catálogo regular.

**Ubicación:** Fresnillo, Zacatecas.

---

## 🎯 Objetivo del sitio

Ofrecer una presencia web clara y accesible para los clientes de la farmacia, donde puedan conocer los servicios, ubicación, horarios y datos de contacto. El sitio es **únicamente informativo**.
